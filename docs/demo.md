# Demo Flow

1. Start the FastAPI backend on port 8000.
2. Start the Next.js app on port 3000.
3. On the landing page, paste: `Urgent: your bank account is suspended. Verify your password now at https://paypal-login.example/verify`.
4. Review the evidence-backed score, red flags, confidence, and provider status.
5. Load `extension/` as an unpacked Chrome MV3 extension and point it at the same local backend.

Without Ollama, VirusTotal, or network access, the result clearly identifies rule-based analysis and unavailable providers; it does not fabricate external intelligence.
